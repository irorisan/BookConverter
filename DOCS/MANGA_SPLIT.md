# 見開き裁断（MangaSplit）

## 目的と入口

従来のAVIF変換用BATは変更せず、**独立した `MangaSplit.bat`** から見開き画像を裁断してCBZを作る。Windows PowerShell **7.6.x**を使用し、`scripts/MangaSplit.ps1`で処理する。AVIF変換・自動命名・容量制御は実施しない。

## 入力・出力

- BATへのドラッグ＆ドロップで、フォルダ / ZIP / CBZ / RARを複数指定可能。
- JPG / JPEG / PNG画像を対象とする。**ファイル名の拡張子直前にある連続した半角数字をページ番号として最優先**する。例：`13DL.me_Net_0004.jpg` → 4、`01.jpg` → 1、`0001.jpg` → 1、`作品名001.jpg` → 1。ファイル名の先頭・途中にある数字（例：`13DL` の 13）はページ番号に使わない。
- 全画像に末尾連番があれば**番号の数値昇順**で並べる。先頭の画像を表紙とし、それ以外を見開きとする。**番号の重複（`001.jpg` / `0001.png` を含む）は失敗**、欠番（例：1,2,4）は**警告して続行**。番号が 1 始まりであることは要求しない。
- **末尾連番を持つ画像と持たない画像が混在した場合は失敗**とし、画像を誤って並べない。全画像に末尾番号が無ければ警告のうえ従来の自然順へフォールバックする（`表紙.png` 等の無連番フォルダ対応）。画像が存在しない場合は失敗。
- **先頭の画像**は画像幅の中央50%（奇数幅は床関数で計算）を残し、1ページの表紙として出力する。
- **先頭以外の画像**は全て見開き画像として扱い、**右半分→左半分**の順で2ページずつ保存する。番号は`0001`（表紙）、`0002`（次画像の右）、`0003`（次画像の左）…。
- 元画像の縦横ピクセルを拡大縮小しない。JPEGは品質95で再エンコードし、PNGは可逆のPNGとして保存する。非可逆JPEGの無劣化コピーは行わない。
- 原本の隣に `元名_裁断.cbz` を作る。既存出力には触れず `元名_裁断 (2).cbz` のように別名保存する。原本・既存CBZは上書き・削除しない。
- 入力CBZの`ComicInfo.xml`がある場合、シリーズ情報を可能な範囲でコピーし、裁断後と整合しない`Pages`要素は除去する。
- 出力された`_裁断.cbz`は再分割を避けるため、入力として拒否する。

## エラー・実行環境・制限

- 画像無し、末尾連番の重複、末尾連番あり/なしの混在、読めない画像、展開失敗、未知形式は巻単位でエラー。`001`という名前の不在だけでは拒否しない。ほかの巻の処理は続行する。
- ZIP/CBZは.NETで解凍。RARは別途WinRAR/UnRARが必要。外部実行ファイルは同梱しない。
- 出力は一時作業領域で作成してから原本と同じディレクトリへ移す。失敗時の一時データは消去する。
- 入力が混在・画像以外を含む場合でも**先頭以外の対象画像は全て見開き**と見なす。片ページ画像を自動判定する機能はない。
- ドラッグ＆ドロップ起動は既存の変換BATと同様に短命なCMDランチャーからWindows Terminal（新規ウィンドウ）へPowerShell 7.6を引き渡す。裁断の処理中も終了後もエラー内容が読めるよう、専用Terminalを閉じずに保持する。Windows TerminalまたはPowerShell 7.6がない場合はBAT上で理由を表示し、画面を保持する。AVIFエンコードとの統合は範囲外。
- Windows CIでは合成画像を使い、中央切り抜き、右→左、ZIP/CBZ/フォルダ、ComicInfo、別名出力、失敗・非破壊を検証する。RAR実ファイルやExplorerドロップの実機検証は範囲外。CIではBATのランチャー経由の引数組立、フォルダ名（空白・日本語・記号）を単一のパスとして安全に渡すこと、成功/失敗でTerminalが即終了しないことも検証する。

## 表紙判定の回帰条件

- 先頭画像名が `01.png`、`0001.jpg`、`作品名01.jpg` でも正常に表紙として中央切り抜きされること。
- `002.png` が先頭画像でも処理を拒否しないこと（名前でなくファイル順を基準にする）。
- 自然順で `作品名2.png` を `作品名10.png` より先に扱い、先頭画像だけ中央切り抜き・残りは右→左へ分割すること。
- 画像が0枚なら出力を作らず失敗すること。入力ファイルや既存CBZを変更しないこと。

## 末尾連番の受け入れ条件

- `13DL.me_Net_0004.jpg` は末尾の `0004` をページ番号 **4** として解釈する。
- `99DL.me_Net_0001.png` と `13DL.me_Net_0002.png` が同じフォルダにある場合、名前の前半に関わらず `99DL...0001` が表紙となる。
- `13DL.me_Net_0001.png`、`13DL.me_Net_0002.png`、`13DL.me_Net_0004.png` は欠番3を警告するが変換する。
- `13DL.me_Net_0001.png` と `別名_1.jpg` は重複ページ1として拒否。原本・既存出力は変更しない。
- 番号なしの `表紙.png` と番号付きの `13DL.me_Net_0002.png` が混在する場合、並びが一意に決まらないため拒否する。
