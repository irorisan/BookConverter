# 漫画・雑誌のBAT入口分離（2026-10-21）

## 背景

旧実装はファイル名から巻数を認識できないと、漫画であっても`IsStandalone`として「単巻・雑誌」に分類し、シリーズ名の一括指定対象から除外していた。元の名前が不統一な普通の漫画でも発生するため、**漫画か雑誌かをファイル名から自動的に決めない**。

## 新しい操作・命名仕様

- `Convert-Manga.bat` = **漫画用（既定）**。以前からのドラッグ＆ドロップ、BAT引数なし起動、同じCUIでの連続投入を維持。**対象が1件でもシリーズ名をバッチごとに1回尋ねる**。Enterは最初の認識された漫画名を初期値として採用。
  - **巻数認識あり・不要タグ除去**: 漫画BATで一括指定した作品名＋巻数 `vNN` に統一する。巻数の直後の枝番 `a/A/b/B`（全角英字を含む）は**すべて除去**する。例: `作品名 v03a.cbz`・`作品名 v03B.cbz`・`作品名 第03巻A.cbz`・`作品名 第03A巻.cbz` → 指定作品名 `v03.cbz`。ファイル名末尾の配布サイトタグ `DL-Raw.Se`（大文字小文字区別なし、スペース・`.`・`_`・`-`・`[]`・`()`・`【】`の区切りを許可）も巻番号認識前に除去する。例: `作品名 v05B [DL-Raw.Se].cbz` → `指定作品名 v05.cbz`。作品名の途中の類似文字列や巻数不明入力・雑誌BATは無条件で削除しない。
  - **巻数認識なし**: 雑誌とは判断せず、**入力名の識別部分を残す**。出力は `指定作品名 - 入力ベース名.cbz`。入力ベース名が指定作品名と完全一致したときだけ `指定作品名.cbz`。存在しない巻番号を捏造せず、元の異なる入力名を同名にまとめてしまわない。たとえば`サンプル漫画 番外編.cbz`と`サンプル漫画 特装版.cbz`は`新作品名 - サンプル漫画 番外編.cbz`と`新作品名 - サンプル漫画 特装版.cbz`になる。
  - **末尾 `_数字` の巻数認識**: 漫画BATに限り、`Manga-Zip.info_10.cbz` や `作品名_１０.cbz` の末尾アンダースコアと数値（任意の枝番 `a`/`b` を含む）を巻数として認識し、指定されたシリーズ名の `v10.cbz` へ統一する。`ドロヘドロ v18.cbz` と `Manga-Zip.info_10.cbz` を一括投入し、シリーズ名「ドロヘドロ」を指定した場合は `ドロヘドロ v18.cbz` と `ドロヘドロ v10.cbz` を出力する。`a`・`b` 両枝番を削除する。`
  - 作品名や特典番号などと紛らわしい数字の意味を**自動では断定できない**ため、今回追加するのは明示的な末尾 `_数字` 形式のみ。日付付き `Weekly_Ascii_2026-10-20` を巻数として扱わない。雑誌BATでは `_10` を含むファイル名も元名のまま出力。
- `Convert-Manga-Magazine.bat` = **雑誌・単巻用**。巻数らしい文字列が含まれるかどうかを問わず、**各入力の元のベース名**に `.cbz`を付けて保存。シリーズ名入力は不要。たとえば`週刊誌 2026-10-20.epub`→`週刊誌 2026-10-20.cbz`、`月刊誌 (15).cbz`→`月刊誌 (15).cbz`。見た目だけで巻物へ振り分けない。
- 両入口は**同じPowerShell変換エンジン**を使う。`Convert-Manga.ps1 -Magazine`で雑誌モードを指定し、既定は漫画モード。待機状態から次を投入しても**起動したBATのモードを固定**する。漫画→雑誌の切替はBATを開き直す。
- フォルダ投入は既存どおり、画像を直下に持つものだけ単一冊子として扱う。シリーズ/コンテナフォルダは子・孫まで探索。出力済みフォルダを再処理しない。
- **元入力は変更・削除しない**。すべて入力元の親の`avif変換cbz/`へ出力し、重複・既存出力はスキップ。名前が未認識でも`v01`を自動付番しない。
- **AVIF品質探索、60MiB判定、70MiB目標、画像順序、EPUB/spine、ZIP Store、WinRAR依存、進捗と終了サマリー**は変更しない。

## テスト・受け入れ条件

1. 漫画BATで巻数不明の名前違いの漫画を2件投入 → シリーズ名の**一括入力あり**、別々のCBZ名で出力。原本と既存出力はSHA-256不変。
2. 漫画BATで巻数あり＋なしを混在 → 巻数ありは`vNN`、巻数なしは`タイトル - 元ベース名`。入力名を意図せず破棄しない。
3. 雑誌BATで巻数ありらしい名前・巻数なしを混在 → いずれも元ベース名保存、シリーズ名入力なし。
4. 2バッチ連続処理 → 起動したモードを維持、作品名・進捗・結果の状態が次バッチへ漏れない。
5. BATへファイルをドラッグ＆ドロップした場合、BAT引数なし起動でコンソールへパスを貼り付けた場合、どちらも動く。日本語・空白・引用符付きの入力も従来どおり。
6. 60MiB以下の小型CBZ（通常・雑誌両方）は出力名だけ変更し、CBZのバイト列自体をコピー。ZIP/RAR/EPUB/フォルダも同じエンジンの従来の処理へ送る。
7. 巻数表記 `v03a` / `v03B` / `第03巻A` / `第03B巻` / `_03ａ` と、末尾 `DL-Raw.Se`・`[DL-Raw.Se]` の組み合わせが、漫画BATでは正しい `v03` に統一される。各ケースの変換済みCBZは原本とSHA-256一致（60MiB以下）。A/Bを取り除いた結果、出力名が重複した場合は既存の重複スキップを維持し、元ファイルは保護する。雑誌BATの元名保持や `DL-Raw.Se` を含む作品名の途中文字列は変更しない。
8. PowerShell 7.6（Windows / .NET 10）の全PS1の構文・UTF-8、テスト成功、最新コミットのGitHub Actions `quality` 成功。実機でのWindows Terminalへのファイルドロップ、RAR/AVIFエンコーダーE2Eは未確認として記録する。
